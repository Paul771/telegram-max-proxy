# Инструкция по настройке прокси для telegram-max-proxy

## Проблема

Telegram API заблокирован в некоторых регионах. Для работы прокси-сервиса необходим доступ к `api.telegram.org`.

## Решение

Проект теперь поддерживает HTTP и SOCKS5 прокси для подключения к Telegram API.

## Настройка прокси

### 1. Получите доступ к прокси-серверу

Варианты:
- Используйте VPN с локальным SOCKS5 прокси
- Арендуйте прокси-сервер
- Настройте свой прокси на VPS за границей

### 2. Добавьте настройки в .env файл

Откройте файл `.env` и добавьте одну из строк:

**Для HTTP прокси:**
```env
HTTP_PROXY=http://proxy-server:port
```

**Для SOCKS5 прокси:**
```env
SOCKS_PROXY=socks5://proxy-server:port
```

**С авторизацией:**
```env
HTTP_PROXY=http://username:password@proxy-server:port
SOCKS_PROXY=socks5://username:password@proxy-server:port
```

### 3. Примеры настройки

**Пример 1: Локальный SOCKS5 прокси (например, через VPN клиент)**
```env
SOCKS_PROXY=socks5://127.0.0.1:1080
```

**Пример 2: HTTP прокси с авторизацией**
```env
HTTP_PROXY=http://user:pass@proxy.example.com:8080
```

**Пример 3: Публичный SOCKS5 прокси**
```env
SOCKS_PROXY=socks5://proxy.example.com:1080
```

### 4. Тестирование подключения

После настройки прокси запустите тест:

```bash
cd telegram-max-proxy
.\venv\Scripts\activate
python test_proxy.py
```

Если подключение успешно, вы увидите:
```
[OK] Подключение успешно!
Bot ID: 1338219014
Bot Username: @your_bot_name
```

### 5. Запуск сервиса

После успешного теста запустите основной сервис:

```bash
python main.py
```

Или через uvicorn:

```bash
uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

## Проверка работы

1. Проверьте статус сервиса:
```bash
curl http://127.0.0.1:8000/health
```

Должен вернуть:
```json
{
  "status": "healthy",
  "telegram_api": "connected",
  "max_api": "connected"
}
```

2. Проверьте информацию о боте:
```bash
curl http://127.0.0.1:8000/bot/info
```

## Популярные VPN с SOCKS5 прокси

Многие VPN клиенты предоставляют локальный SOCKS5 прокси:

- **Shadowsocks** - `socks5://127.0.0.1:1080`
- **V2Ray** - `socks5://127.0.0.1:10808`
- **Clash** - `socks5://127.0.0.1:7891`

Проверьте настройки вашего VPN клиента для получения адреса локального прокси.

## Устранение проблем

### Ошибка: ConnectTimeout
- Проверьте, что прокси-сервер работает
- Проверьте правильность адреса и порта
- Убедитесь, что нет блокировки файрволом

### Ошибка: ProxyError
- Проверьте формат URL прокси
- Убедитесь, что используете правильный протокол (http/socks5)
- Проверьте логин и пароль, если требуется авторизация

### Telegram API все еще недоступен
- Попробуйте другой прокси-сервер
- Убедитесь, что прокси имеет доступ к api.telegram.org
- Проверьте, что прокси не блокирует HTTPS трафик

## Альтернативное решение

Если настройка прокси вызывает сложности, можно развернуть сервис на VPS за границей:

1. Арендуйте VPS (например, DigitalOcean, Linode, AWS)
2. Установите Python и зависимости
3. Скопируйте проект на сервер
4. Настройте .env без прокси
5. Запустите сервис

В этом случае прокси не требуется, так как сервер имеет прямой доступ к Telegram API.
