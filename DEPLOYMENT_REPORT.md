## Известные проблемы

### 1. Кодировка консоли Windows (cp1251)
**Проблема**: Символы Unicode (стрелки, эмодзи) не отображаются корректно в консоли Windows.

**Решение**: 
- Исправлены символы стрелок (→) на ASCII (->)
- Для полного решения: использовать UTF-8 консоль или Docker

**Статус**: ✅ Исправлено в основном коде

### 2. Timeout на /health endpoint
**Проблема**: Health check зависает при отсутствии реальных API токенов.

**Причина**: Попытка подключения к Telegram и MAX API с demo токенами.

**Решение**: Использовать реальные токены или добавить mock режим.

**Статус**: ⚠️ Ожидаемое поведение в demo режиме

## Команды для работы

### Запуск приложения

```bash
# Активировать виртуальное окружение
.\venv\Scripts\Activate.ps1

# Запустить сервер (development)
python main.py

# Запустить с uvicorn
uvicorn main:app --reload --host 127.0.0.1 --port 8000

# Production режим
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4
```

### Тестирование

```bash
# Unit тесты

# С покрытием
```

## Следующие шаги

### Для production развертывания

1. **Получить реальные токены**
   - Telegram Bot Token от @BotFather
   - MAX API Token от платформы MAX

2. **Настроить маппинг чатов**
   - Получить Telegram chat_id
   - Получить MAX user_id
   - Обновить CHAT_USER_MAPPING в .env
