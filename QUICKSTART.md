# Быстрый старт для тестирования

## ✅ Готово к запуску

Все зависимости установлены. Осталось только настроить токены.

## Минимальные шаги для тестирования

### 1. Получите токены (5-10 минут)

**Telegram бот:**
- Напишите [@BotFather](https://t.me/BotFather) → `/newbot`
- Скопируйте токен

**MAX бот:**
- Зарегистрируйтесь на https://business.max.ru/self
- Создайте бота → Интеграция → Получить токен

### 2. Настройте .env файл

Откройте файл `.env` и замените:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
MAX_API_TOKEN=ваш_токен_от_MAX
CHAT_USER_MAPPING={"ваш_telegram_chat_id": "ваш_max_user_id"}
```

**Как узнать chat_id:**
- Напишите боту в Telegram
- Откройте: `https://api.telegram.org/bot<TOKEN>/getUpdates`
- Найдите `"chat":{"id":123456789}`

### 3. Запустите приложение

```powershell
# Активируйте виртуальное окружение
.\venv\Scripts\Activate.ps1

# Запустите
python main.py
```

### 4. Проверьте работу

- Откройте http://localhost:8000/docs
- Напишите боту в Telegram
- Сообщение должно прийти в MAX
